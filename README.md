# Alok Kumar — Portfolio Website

A responsive, static personal portfolio built with HTML, CSS, and vanilla JavaScript. No build step or framework required.

## Preview locally
1. Extract this folder.
2. Open `index.html` in a browser.

## Before publishing
Update these placeholders in `index.html`:
- `your.email@example.com` with your preferred public email.
- LinkedIn and GitHub links in the Contact section.
- Competitive programming profile URLs in the Achievements section.
- Add real repository links to project cards when available.
- Verify role dates, project metrics, and rating values before publishing.

## Deploy free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `alok-kumar-portfolio` (or `YOUR-USERNAME.github.io` for a root profile site).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the Pages deployment. GitHub will display the published URL in Settings → Pages.

Alternative: create a new site on Netlify and drag-and-drop the extracted folder into its manual deploy area.

## Privacy note
Only publish contact information you want to make public. The site uses Google Fonts from a third-party CDN; the site itself has no analytics or tracking code.
