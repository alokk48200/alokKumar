Executive & Product Impact

Built end-to-end support for a new hardware vendor across 5,000+ devices using persistent gNMI tunnel connections. Continuously streamed ~100 Mbps across 16 tunnel & interface telemetry counters into Apache Kafka, stored 10-second hot statistics in Elasticsearch Tier-0 with automated 1-minute rollups into Tier-1, and delivered an interactive UI topology map resolving physical interface connectivity between clubbed Router + Switch devices.

Engineering Architecture & Data Flow Internals

• Persistent gNMI Tunnel Multiplexing: Long-lived gRPC/gNMI Subscribe sessions across 5,000 devices streaming 16 YANG leaf counters (active tunnels, IKE gateway negotiation, packet/byte RX/TX/drops) at ~100 Mbps aggregate ingress.
• Multi-Tier Time-Series Rollup: Kafka consumers flush 10-second statistical windows into Elasticsearch Tier-0 hot indices, while a rollup aggregation pipeline converts 10s buckets into 1-minute Tier-1 indices for sub-second historical UI charting.
• Clubbed Hardware Topology Resolution: Correlated interface descriptors across composite Router + Switch vendor units to map 1:2 breakout links (ge-0/0/0 → sw-eth1, sw-eth2) and 1:1 uplinks (ge-0/0/1 → sw-eth3, ge-0/0/2 → sw-eth4) end-to-end in the UI.
